# Quorum — folder structure

```
quorum/
├── pipeline/     All Python scripts, run in this order:
│                   generate_data.py -> ingest_superstore.py (optional)
│                   -> detect_movements.py
│                   -> statistician.py + chronicler.py + pattern.py + field.py
│                   -> falsifier.py -> arbiter.py
│                   -> access_control.py / persona_render.py / feedback.py
│
├── data/         All CSVs and JSON. Every script reads and writes here via
│                 --datadir / --outdir. kpi_contracts.json is the one
│                 hand-authored file in this folder -- everything else is
│                 generated by the pipeline and safe to delete/regenerate.
│
├── web/          quorum_case_file.html -- the standalone investigation-board
│                 dashboard. Double-click to open in any browser, no server
│                 needed.
│
└── docs/         HOW_QUORUM_WORKS.md/.pdf/.html -- full explanation of every
                  pipeline stage. README.md (this file's sibling from the
                  original data-layer writeup) -- data source details.
```

## Running the full pipeline

All commands below assume you're inside `quorum/data/` (the scripts write
their output relative to `--datadir`, so run them from there and point back
at the scripts with `../pipeline/`):

```powershell
cd quorum\data

python ..\pipeline\generate_data.py --outdir .
python ..\pipeline\ingest_superstore.py --input .\SampleSuperstore.csv --outdir .   REM optional, real data
python ..\pipeline\detect_movements.py --datadir .
python ..\pipeline\statistician.py --datadir .
python ..\pipeline\chronicler.py --datadir .
python ..\pipeline\pattern.py --datadir .
python ..\pipeline\field.py --datadir .
python ..\pipeline\falsifier.py --datadir .
python ..\pipeline\arbiter.py --datadir .
python ..\pipeline\access_control.py --datadir .
python ..\pipeline\persona_render.py --datadir . --user cfo_maria
python ..\pipeline\feedback.py --datadir . --region APAC --weeks 9,10,11,12 --verdict volume --analyst raj --notes "..."
```

Then open `quorum\web\quorum_case_file.html` directly in a browser to see
the dashboard.

## What changed from the old flat folder

Nothing about how any script *works* changed -- every script already took
`--datadir`/`--outdir` as an argument, so this reorganization only required
one real code change: `generate_data.py` didn't have an `--outdir` flag
before (it just wrote to whatever folder you ran it from), so that was
added for consistency with every other script.

This structure was verified end-to-end after the move -- every script listed
above was re-run from scratch in the new layout and produces identical
results to before.
